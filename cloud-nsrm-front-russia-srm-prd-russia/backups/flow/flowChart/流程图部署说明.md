
- PS：可参考chartPlus.vue文件里面的写法，如果不是vue前端框架，其它框架方法也是相似的调用顺序

- 1、在html结构中放入一个div标签，配上一个id，如<div id="flowChartContainer" style="width: 100%; cursor: pointer;"></div>
- 2、调用loadJs文件里面的异步加载js的方法，去异步加载MFlowChart.js文件，加载完后调用改组件的构建流程图API即可

```
    loadJS('./static/MFlowChart/MFlowChart.js', () => {
        MFlowChart.getGrpah('flowChartContainer', {
            idaasVerify,
            width: 1000,
            height: 800,
            env: '', // 是什么环境，可分别传入 dev/sit/uat/prod
            isDraft: false,
            fdId: '',// 流程ID
            appId: '' // 系统ID
        })
    });
```
